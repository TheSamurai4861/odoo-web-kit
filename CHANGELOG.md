# Changelog

All notable changes to this project are documented here. The version follows
Odoo's addon version convention.

## 19.0.5.0.0 - 2026-08-14

### Added

- Four native Website Builder blocks: Hero, Features, Trust and CTA.
- Hero alignment, media-position and tone options.
- Responsive, accessibility, lifecycle and browser acceptance checks.
- Northline demonstration page, screenshots and Builder workflow video.

### Changed

- Centralized local tool discovery and runtime configuration behind
  `WEBKIT_*` environment variables.
- Added portable source validation for contributors and continuous integration.
